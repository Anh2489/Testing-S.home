## CÔNG CỤ KIỂM THỬ

**1. Mục đích**

Tìm hiểu các công cụ hỗ trợ quá trình kiểm thử phần mềm, quản lý lỗi
và kiểm tra dữ liệu trong quá trình thực hiện kiểm thử dự án.

**2. Các công cụ**

- Jira: Quản lý công việc và ghi nhận, theo dõi lỗi
- Postman: Kiểm thử API
- SQL: Kiểm tra và đối chiếu dữ liệu trong cơ sở dữ liệu
- Selenium WebDriver: Tự động hóa kiểm thử Web
- Excel: Quản lý Test Case và Test Data

**3. Jira**

Jira được sử dụng để hỗ trợ quản lý công việc và quản lý lỗi trong
quá trình kiểm thử.
Các nội dung có thể quản lý trên Jira:

- Ghi nhận Bug.
- Mô tả lỗi và các bước tái hiện.
- Theo dõi trạng thái xử lý lỗi.
- Theo dõi tiến độ xử lý lỗi.
- Cập nhật kết quả sau khi lỗi được sửa.

**4. Postman**

Postman được sử dụng để kiểm thử các API của hệ thống.
Các nội dung kiểm tra bao gồm:

- Gửi request đến API.
- Kiểm tra response trả về.
- Kiểm tra HTTP Status Code.
- Kiểm tra dữ liệu trong response.
- Kiểm tra các trường hợp request hợp lệ và không hợp lệ.

**5. SQL**

SQL được sử dụng để kiểm tra và đối chiếu dữ liệu trong cơ sở dữ liệu.

Một số thao tác có thể sử dụng: SELECT, WHERE, JOIN.

Việc kiểm tra dữ liệu giúp xác định dữ liệu được hệ thống lưu trữ
và cập nhật có đúng với kết quả mong đợi hay không.

**6. Selenium WebDriver**

Selenium WebDriver là công cụ phục vụ Automation Testing trên Web.
Selenium có thể được sử dụng để tự động thực hiện các thao tác như:

- Mở trình duyệt.
- Truy cập trang Web.
- Nhập dữ liệu.
- Click các thành phần trên giao diện.
- Kiểm tra kết quả trả về.

Việc xây dựng và thực thi các Test Script bằng Selenium sẽ được
triển khai ở giai đoạn Automation Testing theo kế hoạch.

**7. Excel**

Excel được sử dụng để hỗ trợ quản lý:

- Test Case.
- Test Data.
- Kết quả kiểm thử.
- Thông tin liên quan đến quá trình kiểm thử.

**8. Kết quả**

Em đã tìm hiểu và xác định các công cụ có thể sử dụng để hỗ trợ quá trình
kiểm thử dự án S.Home, bao gồm quản lý lỗi, kiểm thử API, kiểm tra
dữ liệu, kiểm thử Web và quản lý Test Case.
